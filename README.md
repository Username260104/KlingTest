# Entresol — Frontend Prototype

Kling 국내 공식 총판인 Entresol의 B2B 크레딧 공급 메시지를 검토하기 위한 프론트엔드 프로토타입입니다. Kling 본사와의 직접 계약을 기반으로 기업 고객에게 Kling 크레딧을 경쟁력 있는 가격으로 공급하는 범위만 다룹니다.

## 화면

- 단일 스크롤 랜딩 페이지
- Kling 크레딧 공급 문의

크레딧 안내, 공급 방식, 공급 절차와 공식 총판 안내는 메인 랜딩 페이지에 순서대로 통합했습니다. 기존 상세 주소는 대응하는 메인 구간으로 연결됩니다.

문의 폼은 화면 확인용이며 실제 데이터를 저장하거나 전송하지 않습니다.

대외 문구 기준은 [확정 서비스 문구 기준](./docs/확정-서비스-문구-기준.md)을 따릅니다. 이전 기획 문서는 과거 검토 기록으로만 보존합니다.
