# 확정 서비스 문구 기준

## 확정된 사업 범위

1. Kling 국내 공식 총판
2. Kling 본사와 직접 계약
3. 기업 고객 대상 Kling 크레딧 공급
4. 경쟁력 있는 기업 공급가 안내

## 핵심 문장

> Kling 국내 공식 총판으로서, 본사와의 직접 계약을 기반으로 기업 고객에게 Kling 크레딧을 경쟁력 있는 가격으로 공급합니다.

## 사용 가능한 표현

- Kling 국내 공식 총판
- Kling 본사 직접 계약
- 기업 고객 대상 Kling 크레딧 공급
- 기업 공급가
- 예상 필요 수량 확인 후 가격 안내

## 현재 사용하지 않는 표현

- API 공급, 사용권, 연동 또는 기술지원
- Seedance 또는 복수 모델 공급
- 모델 사양이나 영상 규격 구성
- 프로젝트, 월 사용량 또는 맞춤 계약
- 한·중 합작법인
- 국내 계약, 원화 결제 또는 세금계산서 발행
- 근거가 확정되지 않은 최저가, 할인율 또는 최대 할인

추가 서비스나 거래 조건은 사업 담당자가 제공 범위와 공개 문구를 확인한 뒤 이 문서에 먼저 반영합니다.
