# 메인 랜딩 간소화 개편 실행계획

## 1. 문서 목적

현재 프로토타입의 긴 스크롤 구성과 다수의 설명 섹션을 줄이고, 다음 세 가지 메시지가 첫 화면부터 명확하게 전달되는 전환 중심 랜딩페이지로 개편한다.

1. 국내 공식 총판
2. 기업용 크레딧 할인 공급
3. 기업이 원하는 사양과 계약 형태에 맞춘 국내 계약·정산

이 문서는 개편 방향을 확정하기 위한 실행계획이다. 현재 사이트 코드와 배포본은 이 문서 작성 단계에서 변경하지 않는다.

---

## 2. 개편 원칙

- 방문자가 첫 화면에서 공급자의 지위와 가격 경쟁력을 즉시 이해하게 한다.
- 모델의 세부 기능 설명보다 계약, 가격, 기업 거래 편의성을 우선한다.
- 홈 화면은 히어로를 포함해 4개 핵심 구간으로 축소한다.
- 상단 메뉴는 `홈`, `회사·파트너`만 유지한다.
- 견적 중심 표현을 모두 `문의하기`로 통일한다.
- 기존 Kling 기반 다크 디자인 토큰은 유지하되, 히어로에는 자연 배경 이미지를 사용한다.
- 온라인 결제·회원가입·API 발급 기능은 추가하지 않는다.

---

## 3. 최종 페이지 구조

| 페이지 | URL | 역할 | 상단 메뉴 노출 |
|---|---|---|---|
| 홈 | `/` | 핵심 메시지, 공급 조건, 신뢰 정보, 문의 전환 | 노출 |
| 회사·파트너 | `/company` | 회사 정보, 공식 총판 관계, 한·중 합작법인 및 공급 범위 | 노출 |
| 문의하기 | `/contact` | 기업 문의 정보 접수 | CTA로만 노출 |
| 지원 모델 | `/models` | 기존 프로토타입 보존 또는 추후 통합 대상 | 미노출 |
| 계약·도입 | `/plans` | 기존 프로토타입 보존 또는 추후 통합 대상 | 미노출 |

초기 개편에서는 `/models`, `/plans`를 삭제하지 않고 상단 메뉴와 홈 CTA에서만 제거한다. 직접 주소로 접근한 기존 화면은 유지해 복구 가능성을 확보한다. 실제 운영 전에는 홈의 관련 앵커로 리디렉션할지, 완전히 제거할지 최종 결정한다.

## 4. 상단 헤더 개편

### 데스크톱

- 좌측: 현재 심볼과 `Entresol` 워드마크
- 중앙 또는 우측: `홈`, `회사·파트너`
- 최우측 강조 버튼: `문의하기`
- 헤더 높이와 다크 배경은 현재 Kling 토큰 기반 스타일 유지
- 스크롤 시 헤더 고정 유지

### 모바일

- 좌측: 로고
- 우측: `MENU`
- 펼침 메뉴: `홈`, `회사·파트너`, `문의하기`
- 메뉴 항목 수가 적으므로 한 화면 안에서 즉시 선택할 수 있게 구성

### 변경되는 버튼 문구

| 현재 문구 | 개편 문구 |
|---|---|
| 기업 견적 요청 | 문의하기 |
| 도입 상담 신청 | 문의하기 |
| 모델 도입 상담 | 문의하기 |
| 사용량 견적 요청 | 문의하기 |

버튼의 목적지는 모두 `/contact`로 통일한다. 모델이나 문의 유형을 미리 선택하는 기능은 필요할 때만 쿼리 파라미터로 유지한다.

## 5. 홈 랜딩페이지 구성

## 5-1. 히어로: 공식 지위와 가격 혜택

첫 화면 전체를 자연 배경 이미지와 중앙 정렬 문구로 구성한다.

### 권장 레이아웃

- 높이: 데스크톱 기준 화면 높이의 약 75~85%
- 배경: 산, 바다, 숲, 구름 등 시야가 넓고 피사체가 복잡하지 않은 자연 이미지
- 이미지 위에 검정 오버레이와 약한 녹색 그라데이션을 적용해 글자 대비 확보
- 모든 문구와 버튼은 수평·수직 중앙 정렬
- 기존 영상 모델 라우터 콘솔 이미지는 제거

### 화면 문구

**메인 슬로건**

> 국내 공식 총판

**부제목 — 전달받은 원문**

> 기업용 크레딧을 30% 감면된 금액으로

**공개용 권장 표현**

> 기업용 크레딧을 기준가 대비 최대 30% 할인된 금액으로

`30%`의 비교 기준이 확정되어 있다면 `최대`를 제거할 수 있다. 공개 전에는 기준가, 적용 모델, 적용 기간, 사용량 조건을 확인한다.

**CTA**

> 문의하기

### 시각적 우선순위

1. `국내 공식 총판`을 가장 큰 글씨로 표시
2. `30%`를 부제목 안에서 녹색 포인트로 강조
3. `문의하기` 버튼을 부제목 바로 아래 배치
4. 배경 이미지는 분위기만 형성하고 메시지보다 앞서지 않게 처리

### 임시 배경 이미지 운영

- 1차 프로토타입에서는 상업적 사용이 가능한 자연 이미지 또는 별도 생성한 임시 이미지를 로컬 파일로 저장한다.
- 외부 이미지 URL에 직접 의존하지 않는다.
- 임시 파일임을 코드 주석과 문서에 표시한다.
- 최종 제작 단계에서 브랜드 영상 스틸, 실제 제작 사례 또는 정식 라이선스 이미지로 교체한다.

## 5-2. 맞춤 공급: 원하는 사양과 계약 형태

히어로 다음에는 긴 설명 대신 두 개의 큰 카드 또는 좌우 분할 영역을 배치한다.

### 섹션 제목

> 기업이 원하는 방식으로 공급합니다

### 카드 1 — 원하는 사양

**제목**

> 원하는 사양

**설명 문구**

> 필요한 모델, 생성량, 영상 규격과 API 연동 범위에 맞춰 공급 조건을 구성합니다.

**보조 키워드**

- Kling·Seedance 선택
- 프로젝트별 생성량
- API·크레딧 공급
- 기술지원 범위

### 카드 2 — 원하는 계약 형태

**제목**

> 원하는 계약 형태

**설명 문구**

> 테스트 크레딧부터 프로젝트 계약, 월 사용량 계약과 대량 사용 협의까지 기업 상황에 맞춰 제안합니다.

**보조 키워드**

- 선불 크레딧
- 프로젝트 계약
- 월 사용량 계약
- 기업별 맞춤 계약

### 레이아웃 기준

- 데스크톱: 동일 너비의 2열 카드
- 모바일: 세로 1열
- 카드 내부는 제목, 한 문단, 3~4개의 짧은 키워드만 사용
- 별도의 상세보기 버튼은 두지 않아 스크롤 흐름을 단순화

### 섹션 제목

> 국내 기업 거래에 필요한 조건을 갖췄습니다

- 공식 관계와 법인 정보가 확정되기 전에는 과도한 인증 배지 형태를 사용하지 않음

## 6. 홈에서 제거하거나 축소할 요소

현재 홈의 다음 요소는 개편 시 제거한다.

- `Kling and Seedance` 대형 제목
- 영상 모델 라우터 콘솔 그래픽
- 5개 항목으로 구성된 기존 신뢰 띠
- 4개의 세부 서비스 카드
- Kling·Seedance 개별 모델 소개 카드
- 활용 분야 전체 목록
- 6단계 도입 절차
- 가격·계약 안내 반복 영역
- `현재 화면은 프로토타입` 안내 문구
- `콘텐츠 필요` 내부 제작 메모

Kling과 Seedance라는 모델명은 맞춤 사양 카드의 보조 키워드와 문의 폼에서만 노출한다. 홈의 최상위 메시지는 공식 총판 지위와 기업용 가격 혜택에 집중한다.

## 7. 회사·파트너 페이지 개편

상단 메뉴가 두 개로 축소되므로 회사·파트너 페이지가 신뢰 정보를 책임지는 핵심 페이지가 된다.

### 권장 구성

1. 페이지 제목: `국내 계약과 공급을 책임지는 파트너`
2. 회사 기본 정보
3. 한·중 합작법인 구조
4. 공식 총판 계약 관계
5. 국내 공급 가능 모델과 서비스 범위
6. 계약·결제·세금계산서 발행 주체
7. 기술지원 범위
8. `문의하기` CTA

### 화면에 필요한 확정 정보

- 회사명과 법인명
- 대표자
- 사업자등록번호
- 주소와 연락처
- 한·중 합작법인에 대한 정확한 법적 표현
- Kling·Seedance 계약서상 공식 지위 명칭
- 국내 공급 가능 지역과 서비스
- 세금계산서 발행 법인
- 기술지원 채널과 대응 범위

## 8. 문의 페이지 개편

페이지 명칭과 버튼은 모두 `문의하기`로 통일하되, 기업 상담에 필요한 최소 정보는 유지한다.

### 필수 입력

- 회사명
- 담당자명
- 연락처 또는 이메일
- 희망 모델
- 예상 사용량
- 사용 목적
- 문의 내용

### 선택 입력

- 예상 예산
- API 연동 필요 여부
- 도입 희망 시기

### 제출 버튼

> 문의하기

`견적`, `상담`, `도입`처럼 서로 다른 표현은 폼 설명에서만 사용하고 핵심 행동명은 `문의하기`로 고정한다.

---

## 9. 반응형 및 접근성 기준

- 히어로 제목은 모바일에서 2줄 이내로 유지
- 자연 배경 이미지의 중심 피사체가 모바일 크롭에서도 가려지지 않게 설정
- 텍스트 대비를 위해 이미지 위 오버레이를 항상 적용
- 모든 `문의하기` 버튼은 키보드로 접근 가능해야 함
- 버튼과 본문 텍스트의 명도 대비를 확인
- 모바일 메뉴를 열었을 때 세 개의 이동 항목이 한 화면에 표시되어야 함
- 카드의 키워드는 작은 화면에서 자동 줄바꿈
- 배경 이미지는 적절한 크기로 압축해 첫 화면 로딩을 방해하지 않게 함

## 10. 단계별 구현 순서

### 1단계 — 문구와 증빙 기준 확정

- `국내 공식 총판`의 계약서상 사용 가능 명칭 확인
- `30%`의 비교 기준과 적용 조건 확정
- `한·중 합작법인`의 정확한 표기 확정
- 세금계산서 발행 주체 확인

### 2단계 — 공통 헤더와 이동 구조 변경

- 상단 메뉴를 `홈`, `회사·파트너`로 축소
- 데스크톱·모바일의 모든 견적 CTA를 `문의하기`로 변경
- `/contact` 이동 경로 통일

### 3단계 — 홈 화면 재구성

- 기존 홈의 장문 섹션 제거
- 중앙 정렬 히어로 구현
- 임시 자연 배경 이미지와 오버레이 적용
- 맞춤 사양·계약 형태 2열 영역 구현
- 한·중 합작법인·국내 정산·세금계산서 3열 영역 구현
- 최종 문의 CTA 구현

### 4단계 — 회사·파트너와 문의 페이지 정리

- 회사·파트너 페이지를 공식 지위와 법인 정보 중심으로 재배치
- 문의 페이지 제목과 제출 버튼을 `문의하기`로 통일
- 불필요한 내부 프로토타입 문구 제거

### 5단계 — 메타데이터와 공유 이미지 정리

- 페이지 제목과 설명을 새 메시지에 맞춰 수정
- 공유 이미지 문구를 `국내 공식 총판` 중심으로 교체
- 임시 자연 이미지의 라이선스와 교체 필요 여부 기록

### 6단계 — 검증 및 게시

- 홈, 회사·파트너, 문의 페이지 이동 확인
- 기존 `/models`, `/plans` 직접 접근 여부 확인
- 데스크톱과 모바일 레이아웃 확인
- 버튼 문구가 모두 `문의하기`로 통일되었는지 확인
- 빌드와 페이지 렌더 테스트 후 기존 비공개 주소에 새 버전 게시

## 11. 공개 전 필수 확인 사항

| 세금계산서 발행 주체 | 국내 거래 신뢰 | 발행 법인명을 회사 페이지에 명시 |

## 12. 완료 기준

- 첫 화면 중앙에 `국내 공식 총판`이 가장 큰 제목으로 표시된다.
- 제목 아래에 기업용 크레딧 30% 할인 메시지가 표시된다.
- 부제목 아래와 헤더에 `문의하기` 버튼이 각각 존재한다.
- 홈 화면은 히어로, 맞춤 공급, 국내 거래 신뢰, 최종 CTA의 네 구간으로 구성된다.
- 상단 메뉴에는 `홈`, `회사·파트너`만 표시된다.
- `기업 견적 요청` 표현이 사용자 화면에서 제거된다.
- `원하는 사양`, `원하는 계약 형태`, `한·중 합작법인`, `세금계산서 발행 가능`이 각각 독립적으로 인지된다.
- 모바일에서도 핵심 문구와 문의 버튼이 첫 화면 안에서 읽힌다.
- 기존 상세 기획안과 이전 프로토타입 문서는 삭제하지 않는다.
